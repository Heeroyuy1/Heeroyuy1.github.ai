Overview

What Is Woven Model PII Remover?

An on-device desktop tool that scans pasted text for likely PII, highlights matches for review with risk levels, lets you toggle individual detections, and produces cleaned output after confirmation. No uploads — no web server — everything runs locally.

🔒

100% Local Detection

All detection and redaction runs locally using regex and heuristic patterns. No data ever leaves your device. The "Processed Locally" badge reflects actual behavior.

🚨

Risk-Level Classification

Every detection is classified as High (SSN, credit card, bank account), Medium (email, phone, address, DOB, IP), or Low (name, account ID, ZIP) — with explanations.

☑

Toggle-Based Review

Reject false positives before redaction. Toggle individual detections on/off — only confirmed selections are redacted. Full control over what gets cleaned.

🔍

Highlighted Preview

See exactly what was found with risk-colored underlines directly in the text. High = red, Medium = amber, Low = cyan. Clear visual feedback before you redact.

📄

Original / Cleaned Comparison

After redaction, toggle between the original and cleaned views to verify results. One-click copy the cleaned text to your clipboard.

🔧

Easy to Use

Simple paste-and-click workflow. No configuration needed. Clean, intuitive interface with clear visual feedback at every step.

Risk Levels

Three Levels of Sensitivity

Every detection is classified by severity. The Security Summary bar shows counts at a glance, and each item in the detection list carries a colored risk badge.

🔴

High Risk

Red — Immediate Action

Direct financial identity risk. If exposed, could lead to identity theft, financial fraud, or account compromise.

  • ● SSN (Social Security Number)
  • ● Credit Card Number (Luhn-validated)
  • ● Bank Account Number
🟠

Medium Risk

Amber — Review Recommended

Personal contact and location data. Could be used for social engineering, phishing, or targeted attacks.

  • ● Email Address
  • ● US Phone Number
  • ● US Street Address
  • ● Date of Birth
  • ● IP Address (IPv4)
🔷

Low Risk

Cyan — Optional Review

Identifiers and contextual data. Lower direct risk but could aid reconnaissance or link data across sources.

  • ● Person Name (AI-enhanced)
  • ● ZIP / Postal Code
  • ● Account / Customer ID
  • ● Order / Case / Reference ID

Workflow

How to Use PII Remover

A step-by-step walkthrough of the complete detect, review, and redact workflow.

1

Paste or Enter Text

Paste your prompt, document, or any text containing potential sensitive data into the editor panel.

2

Click "Detect PII"

The app scans locally using regex patterns and heuristic name detection. All processing happens on-device — zero network calls.

3

Review the Security Summary

The Security Summary bar shows total detections with counts by risk level (High / Medium / Low). Each detection in the list shows a risk badge, masked value, and explanation.

4

Toggle Detections On/Off

Reject false positives before redaction. Use Select All / Deselect All for bulk operations, or toggle individual items. The highlighted text updates in real time.

5

Click "Remove Selected PII"

Confirm the prompt. The app redacts all confirmed selections and shows the cleaned output with an Original / Cleaned comparison toggle.

6

Copy Cleaned Text

Click "Copy Cleaned Text" or press Enter while the output is focused. The sanitized text is now safe to paste into AI prompts, documents, or workflows.

🔎 Highlighted Text

Risk-colored underlines appear directly in your text: red for high risk, amber for medium, cyan for low. See exactly what was found before you redact.

🔄 Live Summary Updates

Toggle a detection on/off and the Security Summary counts update instantly. The highlighted text also reflects the change in real time.

📄 Compare Toggle

After redaction, switch between Original and Cleaned views to verify that only the right data was removed. Nothing hidden, nothing unexpected.
